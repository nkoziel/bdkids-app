# BDkids

Bibliothèque BD jeunesse — savoir en un coup d'œil quels tomes sont déjà possédés, série par
série, avant d'acheter un nouveau tome en librairie.

Pas de manga, pas de suivi de lecture : juste possédé / non possédé, par tome.

## Statut

Projet en tout début de mise en place. Voir `CLAUDE.md` pour l'état d'avancement et les
décisions d'architecture.

## Développement

```
npm install
npm run dev
```

## Build

```
npm run build
```
